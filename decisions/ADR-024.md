## ADR-024 — Enjoy installs as an app and drives offline (a PWA)

**Status:** Accepted (the owner, 2026-11-01: "Installable/offline web", then "Just deploy
the enjoy mode"). Built 2026-11-01 on `feat/enjoy-pwa`. The choices under *Decision* that
the owner did not make are marked **(default)**: each is reversible, and the owner may
change it.

Written in `decisions/` rather than appended to DECISIONS.md: #146 and #148 (open) both
append ADR-023 there, and three appends at one place conflict in any merge order.
`reviews/PROPOSAL-modularize.md` step A3 moves every full text here anyway.

### Context

The owner asked to "plan deployment", then chose installable/offline web over store apps,
commercial hosting, or only releasing the open PRs, and narrowed it to Enjoy. The site
was already deployed (GitHub Pages from `main`, 1-2 min per deploy), but had no manifest
and no service worker. Pages sends `cache-control: max-age=600` on every file, so nothing
worked offline and a phone re-checked every file after 10 minutes. Measured on the build
of `2aa1710`:
- Enjoy needs the app shell (main bundle 491 KB raw / 120 KB gzipped, the live and par
  worker chunks, the 24 KB sound worklet) and one grid per engine (5.07 MB raw, 1.06 MB
  over the wire; 11 roster engines, 16 grids in all with /drive's presets);
- Enjoy never loads Pyodide (16.5 MB) or the solver bundle (452 KB): the Enjoy e2e checks
  it.

### Decision

1. **Angular's service worker** (`@angular/service-worker`, at core's exact version, its
   peer dependency), not a hand-written one. It keeps every page on one version of the
   app's files (ADR-010's rule against a mix of old and new physics), checks hashes, and
   needs no new tooling. ADR-005's pinned Angular still holds; the new package moves with
   it. Off under `ng serve`.
2. **What is kept** (`web/app/ngsw-config.json`):
   - the app shell, fetched up front (696 KB raw: bundle, worker chunks, worklet, icons,
     manifest, index);
   - **grids lazily (default):** an engine's grid is kept once it has been started
     online. A deploy re-fetches a kept grid only if its hash changed. Prefetching all
     eleven roster grids would cost ~12 MB of mobile data on the first visit, unasked.
   - **never Pyodide or the solver bundle:** Dyno, Grid, Cycle, Spec, Sweep and
     Durability stay online-only. Drive's presets work offline once started, like Enjoy's.
3. **Installing opens /enjoy (default),** landscape and full screen, scoped to the whole
   site (`manifest.webmanifest`). The icon is a tachometer in the app's three colours
   (`scripts/icon.svg`, rendered by `scripts/make-icons.mjs`).
4. **An update is offered, never forced:** a bar ("A new version is ready. Reload /
   Later") when the new version has downloaded; it checks whenever the page comes back
   into view. A forced reload would end a drive.
5. **Offline, an engine never started says so:** "This engine isn't on this device yet:
   start it once while online, and it works offline after that."

### Trade-offs

- **Positives:** installs from Chrome on Android (the S9+); starts instantly and drives
  with no network; a deploy reaches an installed phone at its next look, with a visible
  Reload instead of a silent stale copy; no store, fee or review; the step any later store
  wrapper (TWA, Capacitor) would reuse.
- **Costs:** a stale-version trap for anyone testing a deploy (see *Consequences*); 5 MB
  of storage per engine kept; iOS installs only through Share → Add to Home Screen, keeps
  ~50 MB per site and may evict it after weeks unused, and has no Vibration API (ADR-016);
  every page now runs under a service worker, so the existing e2e checks run with one too.

### Not done (each its own decision if wanted)

- a "Keep every engine offline" button (~12 MB, the user's choice);
- a custom domain, store listings (a Play Store TWA needs `assetlinks.json` at the
  domain's root, which a github.io project page can't serve), commercial hosting (ADR-010:
  Pages' terms prohibit commercial SaaS);
- offline Expert mode (Pyodide is 16.5 MB).

### Consequences

- **Testing a deploy on a phone:** the first open after a merge may show the old version,
  with the Reload bar once the new one has downloaded. Tap Reload before judging a change.
- An Angular bump must bump `@angular/service-worker` to the same version (an exact peer).
- `e2e:offline` (CI, the web e2e job) shuts the server down and drives; Pages' workflow
  refuses a build without `ngsw.json`'s two groups, the manifest or the icons, or with
  Pyodide in the offline copy.
- `*.png` is ignored repo-wide; `.gitignore` excepts `web/app/public/icons/*.png`.
- Revisit if a phone check finds the lazy grids confusing (a first offline drive fails for
  engines never started), or if store apps come back on the table.
